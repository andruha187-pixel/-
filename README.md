# polymarket-maker-bot (DRY RUN)

Мейкер-бот для 15-минутных Up/Down рынков Polymarket по мотивам кошелька 0xb945…db68,
с исправлением его главной слабости — перекоса позиции. Сейчас работает ТОЛЬКО в симуляции.

## Логика
1. Справедливая вероятность Up = Φ(ln(P/P0)/(σ·√t)); P — Chainlink, подтянутый к текущему Binance, P0 — цена на старте окна.
2. Ставит лимитные BID на Up и Down: fair − min_edge/2 → сумма пары ≈ 1 − min_edge. Только мейкер: цена всегда ниже лучшего ASK.
3. Управление запасом: цена сдвигается против перекоса (skew_per_share); при перекосе ≥ max_imbalance перевешивающая сторона не котируется; лёгкая сторона докупается агрессивнее, пока цена пары ≤ hedge_max_pair.
4. Защита: рывок Binance ≥ kill_bps за 5с → заявки снимаются на kill_cooldown; не котирует в начале/конце окна и когда исход почти решён.
5. Держит до резолва. Ребейт оценивается как rebate_share × fee_rate × шт × p × (1−p) — на данных кошелька это ≈0,75% оборота, совпадает с его реальными выплатами.

## Симуляция исполнения
По реальным сделкам и стакану Polymarket с очередью: сначала съедается объём, стоявший на нашей цене до нас; перестановка заявки — потеря очереди; зеркальные сделки по второму токену учитываются. `queue_mult` > 1 — консервативнее.
